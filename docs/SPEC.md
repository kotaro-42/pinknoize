# Pink Noise — 製品仕様（優先度順）

## 優先度と達成目標

| 順位 | 要件 | 目標 | 現フェーズでの位置づけ |
|------|------|------|------------------------|
| 1 | **オフライン動作** | 初回同期後、ネットワークなしで起動・再生・音量調整できる | **必須達成**（PWA + SW + localStorage + 同梱 RNBO） |
| 2 | **画面オフでも途切れない** | ロック画面・消灯後も再生が継続する | **ベストエフォート**（Web 制約あり。下記「iOS 制約」参照） |
| 3 | **バックグラウンド再生** | 他アプリ使用中も再生継続 | **ベストエフォート**（同上） |
| 4 | **再生・停止** | 明示操作のみ開始。停止後に再開可能 | **必須達成** |
| 5 | **音量調整** | 0–100%、リアルタイム、0% = ミュート | **必須達成**（GainNode。パッチ未変更） |

仕様上、**1・4・5 は PWA で保証する**。**2・3 は iPadOS の WebKit 制約により保証しない**。可能な範囲の対策を実装し、保証が必要なら Phase 2（ネイティブシェル）へ移行する。

---

## アーキテクチャ概要

```text
index.html + style.css
       │
       ├── sw.js          … 静的 precache（キャッシュ優先）
       │
       └── js/app.js      … UI / オフライン保存 / RNBO / 音量（単一ファイル）
              └── js/rnbo.min.js（同梱、CDN なし）
```

### レイヤ責務

1. **オフライン** — `sw.js` の precache + `localStorage` にパッチ JSON テキスト
2. **セッション維持（ベストエフォート）** — 無音 `<audio loop>` + 復帰時 `AudioContext.resume()`
3. **再生・音量** — RNBO パッチ + GainNode（優先度 4・5）

JS は **ES5 スタイル**（`var` / `function`、オプショナル構文なし、`finally` なし）。

## オフライン要件（詳細）

### 対応 OS（目安）

- **iOS / iPadOS 13.4 以上**（`?.` 未使用の ES5 互換 JS に寄せている）
- **iPad mini 2/3（iOS 12 まで）** は RNBO / Web Audio の面で**非推奨・未保証**
- プライベートブラウズでは `localStorage` が使えず、オフライン保存が弱くなることがある

### 初回セットアップ（オンライン）

1. ユーザーが HTTPS 上でアプリを開く（ホーム画面追加を推奨）。
2. Service Worker が install し、一覧の静的資産を precache。
3. アプリが `Pinknoise.json` を fetch し、**localStorage に保存**。
4. UI に「オフライン利用可」を表示。

### 2 回目以降（オフライン）

1. `index.html` ほかはキャッシュから配信。
2. パッチ読み込み: `fetch` → 失敗時 **localStorage** → 失敗時エラー表示。
3. 再生・停止・音量はすべてローカルグラフ内で完結。

### キャッシュ更新

- `sw.js` の `CACHE_NAME` を更新すると旧キャッシュを削除。
- オンライン時は navigation / 主要 JS をネットワーク優先で更新しつつオフライン時は旧版でも動作。

## 再生・停止・音量（詳細）

| 操作 | 挙動 |
|------|------|
| 再生 | ユーザータップ必須。iOS は `pointerdown` でエンジン初期化を先行。 |
| 停止 | パッチ volume → 0。セッション維持用 audio も停止。 |
| 音量 | スライダー 0–100%。Web Audio GainNode。0% は完全無音。 |

---

## iOS / iPadOS 制約と Phase 2

Web アプリ（PWA 含む）では **Web Audio API（RNBO）** を OS がバックグラウンドや画面ロック時に **サスペンドする**ことがある。Apple はメディア要素経由の再生を優先し、AudioWorklet グラフの常時バックグラウンド実行は保証していない。

本プロジェクト Phase 1（現状）:

- 前面表示・スタンドアロン PWA: 再生を主眼。
- セッション維持の**試行**を実装するが、2・3 を SLA として扱わない。

Phase 2（優先度 2–3 を保証する場合）:

- Capacitor / WKWebView + **ネイティブ `UIBackgroundModes: audio`**、または RNBO 相当をネイティブでラップ。
- 同一 UI 資産を WebView に載せ、オフライン資産は引き続きバンドル。

## 受け入れ基準（テスト観点）

### 必須（1, 4, 5）

- [ ] 初回オンライン後、機内モードで起動できる。
- [ ] 機内モードで再生・停止・音量が動作する。
- [ ] パッチ JSON / RNBO を外部ネットに取りに行かない。

### 任意（2, 3）— 記録のみ

- [ ] ロック画面後 30 秒、音が続くか（機種・OS 依存）。
- [ ] Safari から別アプリへ切り替え、音が続くか。
- 失敗しても Phase 1 リリース判定には含めない。
